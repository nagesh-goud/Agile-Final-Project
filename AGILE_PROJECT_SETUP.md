# Agile Final Project — Sprint Setup

## Sprint 1 milestone

**Title:** Sprint 1  
**Description:** Complete core product catalog features.

Assign issues **#1–#4** to this milestone:
- #1 Create a product — 3 points
- #2 Retrieve a product — 2 points
- #3 Update a product — 3 points
- #4 Delete a product — 2 points

## GitHub Projects board

Create a project named **Agile Final Project Sprint** and add issues #1–#10 from this repository.

Recommended workflow columns/status values:
- Product Backlog
- Sprint Backlog
- In Progress
- Done

Recommended starting placement:
- **Sprint Backlog:** #1–#4
- **Product Backlog:** #5–#10
- Move cards to **In Progress** when work starts and **Done** only after completion.

## Story point estimates

The point estimates are recorded in each issue body. If the assignment requires a Projects custom field, add a number field named **Story Points** and enter these values:

| Issue | Story | Points |
|---|---|---:|
| #1 | Create a product | 3 |

| #3 | Update a product | 3 |
| #4 | Delete a product | 2 |

## Evidence to capture for submission
